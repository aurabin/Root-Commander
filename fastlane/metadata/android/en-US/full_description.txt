RootCommander is a free and open-source Android file manager with an accessible dashboard. Select two folders through Android's document picker, browse files and copy selected files between folders. It also provides links to Android settings, an APK installation handoff to Android, optional local shell commands, and links to Termux and Shizuku. Root access is optional and is not provided by this app. Android storage and installation permissions remain in effect. The app is under active development and has not yet been tested on a physical device.
