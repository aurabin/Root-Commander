# RootCommander – Einschränkungen verstehen und legal lösen
## DE – Deutsch (einfache Sprache)
RootCommander kann viele eigene Grenzen entfernen. Android-Schutzregeln gelten trotzdem.

1. **500 Dateien:** Die Liste soll Dateien in kleinen Gruppen nachladen. So bleibt das Handy schnell.
2. **Langsame Ordner:** Dateien werden im Hintergrund gelesen. Die Oberfläche bleibt bedienbar.
3. **Kleines Display:** Große Schaltflächen, lesbare Texte und eine umschaltbare Ein-Fenster-Ansicht helfen.
4. **APK installieren:** Wähle die APK aus. Android fragt, ob die Installation erlaubt ist. Du entscheidest.
5. **Geschützte Ordner:** Nutze die Android-Ordnerauswahl. Einige Systemordner bleiben gesperrt.
6. **Root:** Nur mit einem Gerät, das bereits Root-Rechte hat. RootCommander kann Root nicht von selbst freischalten.
7. **Alte Android-Versionen:** Der Quellcode ist für Android 7.0 und neuer eingestellt. Geräte müssen getestet werden.
8. **Neue Android-Versionen:** Updates und Tests sind nötig. Keine App ist für alle künftigen Versionen garantiert.
9. **Sprachen:** Deutsch, Englisch, Französisch und Portugiesisch. Weitere Sprachen können folgen.
10. **Datenschutz:** Keine heimliche Fernsteuerung. Jede wichtige Aktion braucht eine bewusste Freigabe.

**Auf deinem Moto G14:** Einstellungen → Apps → Spezieller App-Zugriff → Unbekannte Apps installieren. Wähle die App, mit der du die APK öffnest. Erlaube die Installation nur, wenn du der Quelle vertraust. Danach kannst du die Erlaubnis wieder ausschalten.

**Warnung:** Das Entsperren des Bootloaders kann Daten löschen und Sicherheitsfunktionen beeinträchtigen. Es ist keine Voraussetzung für die normalen Dateifunktionen.

## EN – English (simple language)
RootCommander can remove limits in its own code. Android security rules still apply.

1. **500 files:** Load more files in small batches.
2. **Slow folders:** Read files in the background.
3. **Small screens:** Use large buttons and a single-pane option.
4. **APK install:** Android asks for permission. You decide.
5. **Protected folders:** Use the Android folder picker. Some system folders remain restricted.
6. **Root:** Works only if root access is already available and approved.
7. **Older Android:** Configured for Android 7.0+. Device testing is needed.
8. **New Android:** Updates and tests are needed.
9. **Languages:** German, English, French and Portuguese.
10. **Privacy:** No hidden remote control.

**Warning:** Unlocking a bootloader may erase data and reduce security.

## FR – Français (langage simple)
RootCommander peut supprimer certaines limites de son code. Les règles de sécurité Android restent actives.

1. **500 fichiers :** Charger les fichiers par petits groupes.
2. **Dossiers lents :** Lire les fichiers en arrière-plan.
3. **Petit écran :** Grands boutons et affichage à un panneau.
4. **Installer un APK :** Android demande votre autorisation.
5. **Dossiers protégés :** Utiliser le sélecteur Android. Certains dossiers restent bloqués.
6. **Root :** Possible seulement si l'appareil possède déjà cet accès.
7. **Ancien Android :** Configuration à partir d'Android 7.0 ; tests nécessaires.
8. **Nouvel Android :** Mises à jour et tests nécessaires.
9. **Langues :** Allemand, anglais, français et portugais.
10. **Vie privée :** Aucun contrôle à distance caché.

**Attention :** Déverrouiller le chargeur de démarrage peut effacer les données et réduire la sécurité.

## PT – Português (linguagem simples)
O RootCommander pode remover limites do próprio código. As regras de segurança do Android continuam válidas.

1. **500 arquivos:** Carregar arquivos em pequenos grupos.
2. **Pastas lentas:** Ler arquivos em segundo plano.
3. **Tela pequena:** Botões grandes e opção de painel único.
4. **Instalar APK:** O Android pede a sua autorização.
5. **Pastas protegidas:** Usar o seletor de pastas do Android. Algumas pastas continuam bloqueadas.
6. **Root:** Só funciona se o dispositivo já tiver acesso root autorizado.
7. **Android antigo:** Configurado para Android 7.0 ou superior; testes necessários.
8. **Android novo:** Atualizações e testes são necessários.
9. **Idiomas:** Alemão, inglês, francês e português.
10. **Privacidade:** Sem controle remoto oculto.

**Atenção:** Desbloquear o bootloader pode apagar dados e reduzir a segurança.

## Technischer Status / Technical status
- Android 7.0+ ist als Mindestversion eingestellt, aber nicht auf allen Geräten geprüft.
- Ordnerabfragen laufen im Hintergrund.
- Die Anzeigegrenze von 500 Einträgen besteht noch. Seitenweises Nachladen ist ein geplanter Umbau, keine bereits implementierte Funktion.
- Root- und Android-Sicherheitsgrenzen werden nicht umgangen.
