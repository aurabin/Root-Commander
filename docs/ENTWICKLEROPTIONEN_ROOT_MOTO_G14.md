# Entwickleroptionen und Root auf dem Motorola Moto G14

## Deutsch – einfache Sprache

RootCommander kann die Entwickleroptionen **nicht selbst einschalten**. Das muss der Besitzer am Handy tun.

1. Öffne **Einstellungen**.
2. Öffne **Über das Telefon**.
3. Suche die **Build-Nummer**. Sie kann unter **Geräteinformationen** stehen.
4. Tippe siebenmal auf die Build-Nummer.
5. Gib bei Bedarf deine PIN ein.
6. Öffne **Einstellungen → System → Entwickleroptionen**.

**USB-Debugging** erlaubt ADB-Verbindungen nach Bestätigung am Handy. **OEM-Entsperrung** kann bei unterstützten Geräten die Bootloader-Entsperrung vorbereiten. Beides ist **kein Root-Zugriff**.

Für echtes Root muss die genaue Gerätevariante und Firmware geprüft werden. Der Bootloader muss entsperrbar sein. Die Entsperrung kann sämtliche Nutzerdaten löschen. Ein falsches Start-Image kann das Handy unbrauchbar machen. RootCommander darf weder die Entsperrung noch das Flashen ungefragt starten.

**Root prüfen:** RootCommander hat eine Schaltfläche zur Prüfung vorhandener `su`-Rechte. Sie richtet Root nicht ein. Wenn Android oder Magisk nach einer Erlaubnis fragt, entscheidet der Besitzer.

## English – plain language

RootCommander cannot enable Developer options by itself. On the phone, open **Settings → About phone**, find **Build number**, tap it seven times, and enter your PIN if asked. Then open **Settings → System → Developer options**.

USB debugging is not root. OEM unlocking is not root. Unlocking the bootloader may erase your data. Do not flash an image unless the exact device and firmware are verified.

## Français – langage simple

RootCommander ne peut pas activer les options pour les développeurs tout seul. Sur le téléphone, ouvrez **Paramètres → À propos du téléphone**, trouvez **Numéro de build**, appuyez sept fois et saisissez votre code si nécessaire. Ouvrez ensuite **Paramètres → Système → Options pour les développeurs**.

Le débogage USB et le déverrouillage OEM ne donnent pas les droits root. Déverrouiller le chargeur de démarrage peut effacer les données.

## Português – linguagem simples

O RootCommander não pode ativar as opções do desenvolvedor sozinho. No celular, abra **Configurações → Sobre o telefone**, encontre **Número da versão**, toque sete vezes e digite seu PIN se necessário. Depois abra **Configurações → Sistema → Opções do desenvolvedor**.

Depuração USB e desbloqueio OEM não são acesso root. Desbloquear o bootloader pode apagar seus dados.
